# React Season Effects Demo

Interactive demo application for the `react-season-effects` library.

## Running the Demo

```bash
# From the root of the monorepo
npm install
npm run dev
```

Or run just the demo:

```bash
cd apps/demo
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Features

- 🎮 Interactive controls for all effect parameters
- 🎨 Live code examples
- 📱 Responsive design
- ⚡ Real-time updates

## Tech Stack

- Next.js 14 (App Router)
- TypeScript
- CSS Modules
- react-season-effects library

## Development

The demo automatically hot-reloads when you make changes to either the demo code or the library code (thanks to Turborepo).

## Building for Production

```bash
npm run build
npm start
```
